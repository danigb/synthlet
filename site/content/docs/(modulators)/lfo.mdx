---
title: LFO
description: A Low Frequency Oscillator module
package: lfo
---

```ts
import { Lfo } from "synthlet";

const lfo = Lfo(audioContext, {
  frequency: 0.5,
  type: LfoType.Sine,
  amplitude: 0.5,
  offset: 0.5,
});
```

## Params

- `frequency`: the frequency of the oscillator in Hz. Default is 10Hz. Range: [0-200]
- `type`: the type of the oscillator. You can use `LfoType` enum. Default is `LfoType.Sine`.
- `gain`: the amplitude of the oscillator. Default is 1. Range: [0-10000]
- `offset`: the offset of the oscillator. Default is 0. Range: [-1000, 1000]

Available waveform types (through `LfoType` enum) are:

- `0`: Zero
- `1`: Sine
- `2`: Triangle
- `3`: RampUp
- `4`: RampDown
- `5`: Square
- `6`: ExpRampUp
- `7`: ExpRampDown
- `8`: ExpTriangle
- `9`: RandSampleHold
- `10`: Impulse
