```ts
import { Lfo } from "synthlet";

const lfo = Lfo(audioContext, {
  frequency: 0.5,
  type: LfoType.Sine,
  amplitude: 0.5,
  offset: 0.5,
});
```

## Params

- `frequency`: the rate in Hz, a-rate. Default is 10. Range: [-200, 200].
  **Bipolar**: a negative rate runs the phase backwards, and `frequency: 0`
  freezes the LFO on the value at `phase`. A modulated rate is tracked per
  sample; an unmodulated one costs nothing.
- `type`: the type of the oscillator. You can use `LfoType` enum. Default is `LfoType.Sine`.
- `gain`: the depth of the oscillator. Default is 1. Range: [-20000, 20000]. A
  **negative gain inverts the waveform** — that is how you get a filter that
  closes as the amp opens, or two LFOs in antiphase.
- `offset`: where the waveform is centred. Default is 0. Range: [-20000, 20000].
  A unipolar 0…1 modulator is `gain: 0.5, offset: 0.5`; a filter cutoff swept
  over its whole range is `gain: 10000, offset: 10000`.

- `sync`: a-rate. A **rising edge** — the transition from non-positive to
  positive, [synthlet's one gate contract](/docs/gates-and-triggers) — restarts
  the phase at `phase`. Unconnected it is 0 and nothing happens.

`gain` and `offset` carry the same range as `Ad`, `Adsr` and `Param`, which
compute the identical `x × gain + offset`.

- `gate`: a-rate. A rising edge restarts the **depth ramp**. Not `sync` — see
  below.
- `delay`: seconds held at zero depth before the ramp begins. Default 0. Range:
  [0, 10].
- `attack`: seconds from zero to 99% of full depth. Default 0. Range: [0, 10].

## The top of the range

**Above roughly 20 Hz this stops being a modulation source.** The shapes are
naive, and deliberately: at LFO rates the aliased images fold back onto
harmonics, so there is nothing inharmonic for a band-limiting scheme to remove.
At the top of the range the discontinuous shapes show it — measured alias SNR at
200 Hz is 23.6 dB for the ramps, 25.4 for the square and 16.3 for the exponential
ramps, against 96 dB or better for all of them at 100 Hz.

Audio-rate _modulation_ at 50–100 Hz is clean and useful, which is why the
ceiling stays where it is. For an audio-rate _oscillator_, use
[PolyblepOscillator](/docs/sources/polyblep), which is band-limited.

## Fading in

Vibrato that arrives a moment after the note is the most common thing an LFO
does. `delay` and `attack` are that, and `gate` starts it:

```ts
const vibrato = Lfo(audioContext, {
  frequency: 5,
  gain: 10,
  delay: 0.3, // 300 ms of nothing
  attack: 0.7, // then 700 ms fading up to full depth
  gate, // restarted by the note
});
```

**`delay: 0, attack: 0` — the defaults — means no envelope at all.** The depth is
1, `gate` is ignored, and the output is bit-identical to a build without it.

| Behaviour              | What happens                                      |
| ---------------------- | ------------------------------------------------- |
| Rising edge on `gate`  | The fade restarts at zero depth                   |
| Gate held high         | The fade advances — legato is **one** ramp        |
| Gate falls             | The fade **freezes**; it does not reset           |
| `gate` never connected | Armed at construction: it fades in once and stays |

`attack` is seconds to **99%** of full depth, the same meaning `Ad` and `Adsr`
give theirs. A Juno-6 with its delay slider at maximum is `attack: 6.91`.

**`sync` and `gate` are different parameters.** `sync` resets the _phase_;
`gate` restarts the _depth ramp_. A Juno's LFO free-runs while its depth fades
in, which is only expressible if the two are separate.

## Options

`phase` is a **construction option**, not an `AudioParam`: it is a one-time
initial condition, and an `AudioParam` would imply it meant something
continuously. It is also where a `sync` edge restarts the phase. A number is
taken modulo 1, so `1.25` and `-0.75` both mean `0.25`; `"random"` draws once
per instance.

## Starting it

Without `sync`, every `Lfo` in an `AudioContext` free-runs from context time
zero — so two at the same rate are the _same signal_, forever, and a note-on
cannot restart a vibrato.

```ts
// Per-note vibrato: the voice's gate restarts the LFO.
const vibrato = Lfo(audioContext, { frequency: 5, gain: 10, sync: gate });
vibrato.connect(osc.frequency);

// Tempo sync: no `bpm` param and no division enum — `clock.gate` is the
// mechanism, and the division is `frequency` relative to the tempo.
const clock = Clock(audioContext, { bpm: 120 });
const perBeat = Lfo(audioContext, { frequency: 2, sync: clock.gate });

// Two independent wobbles, without detuning either.
const wobble = () => Lfo(audioContext, { frequency: 0.3, phase: "random" });
```

Holding `sync` positive fires **once**, not once per sample. The reset lands on
the sample the edge was detected on: unlike the oscillators, this package does
not interpolate the sub-sample crossing instant — 2.9 ms is nothing against a
5 Hz cycle.

## Shapes

**Every continuous shape crosses zero going up at phase 0** — a modulation
source's zero point is no modulation. `Square` and `Impulse` are the exceptions
and cannot be otherwise: a square has no zero crossing, and the impulse's single
sample _is_ the cycle boundary.

| `LfoType`            | φ=0  | φ=¼     | φ=½  | φ=¾     | Jumps at |
| -------------------- | ---- | ------- | ---- | ------- | -------- |
| `None` (0)           | 0    | 0       | 0    | 0       | —        |
| `Sine` (1)           | 0    | +1      | 0    | −1      | —        |
| `Triangle` (2)       | 0    | +1      | 0    | −1      | —        |
| `RampUp` (3)         | 0    | +0.5    | −1   | −0.5    | φ=½      |
| `RampDown` (4)       | 0    | −0.5    | +1   | +0.5    | φ=½      |
| `Square` (5)         | +1   | +1      | −1   | −1      | φ=0, φ=½ |
| `ExpRampUp` (6)      | 0    | +0.1246 | −1   | −0.1246 | φ=½      |
| `ExpRampDown` (7)    | 0    | −0.1246 | +1   | +0.1246 | φ=½      |
| `ExpTriangle` (8)    | 0    | +1      | 0    | −1      | —        |
| `RandSampleHold` (9) | held | held    | held | held    | φ=0      |
| `Impulse` (10)       | 1    | 0       | 0    | 0       | φ=0      |

The last two are stochastic and have no such row. What they promise instead is a
range and a continuity:

| `LfoType`         | Promises                                                                                           |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| `RandSmooth` (11) | In ±1. One random target per cycle, faded between targets — continuous, with no corner at a target |
| `Drift` (12)      | In ±1. Two octaves of gradient noise along the phase — a rate, but no audible period               |

`RandSampleHold` steps, and that is its point — it is also the loudest thing this
module emits, at a measured 1.41623 of single-sample step at 5 Hz where a sine's
largest is 0.00071. `RandSmooth` and `Drift` are the continuous members, both
under 0.005 at the same rate. They are not redundant with each other:
**`RandSmooth` has a beat** — every local extremum is a cycle boundary — and
**`Drift` does not**.

The interpolation is Perlin's quintic fade rather than a straight line: linear
interpolation between random targets has a discontinuous derivative at every
target, so a smoothed random on a cutoff would have an audible corner once a
cycle. `Drift` is one-dimensional gradient (Perlin) noise along the phase, per
Popov 2018.

**None of these is a noise source.** [Noise](/docs/sources/noise) is white and
pink at audio rate; these are one random value per LFO cycle.

Every shape swings the full ±1 and averages to zero over a cycle, so `gain` is
the whole depth and nothing here adds DC to what it modulates.

The three `Exp*` shapes are their linear partners bent inward: same zeros, same
peaks, same sign everywhere, and only the path between them differs.
