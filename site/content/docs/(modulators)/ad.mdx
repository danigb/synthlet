This is a two-stage envelope generator - attack, then decay straight back to
zero - useful to create percussive sounds.

Unlike ADSR, this envelope has no sustain: it is fired and runs to completion,
so it can finish before the trigger is released.

Both stages are in seconds, the same as the ADSR: `attack` is the time to reach
the peak, and `decay` the time to fall to silence (−60 dB).

```ts
import { AdEnv, registerAdWorklet } from "synthlet";

const audioContext = new AudioContext();
await registerAdWorklet(audioContext);

const ad = AdEnv(audioContext, {
  attack: 0.01,
  decay: 0.3,
  gain: 1,
});
const osc = new OscillatorNode(audioContext);
osc.start();
const amp = new GainNode(audioContext, { gain: 0 });
ad.connect(amp.gain);

ad.trigger.value = 1;
```

## Parameters

- `attack`: The time to reach the peak, in seconds. Default is 0.01.
- `decay`: The time to fall to silence (−60 dB), in seconds. Default is 0.1.
- `trigger`: Fires the envelope on the rising edge, when it goes from 0 to a positive value. Move it back to 0 before firing it again.
- `offset`: The offset of the envelope. Default is 0.
- `gain`: The gain of the envelope. Default is 1.
