A Voltage Controlled Amplifier (VCA) module with an Attack-Decay-Sustain-Release (ADSR) envelope

Use it to add an envelope to the synth voices.

```ts
import { AdsrAmp, OscillatorNode } from "synthlet";

const osc = new OscillatorNode(audioContext, {
  frequency: 440,
});
const vca = AdsrAmp(audioContext, {
  gain: 0.5,
  attack: 0.01,
  decay: 0.1,
  sustain: 0.5,
  release: 0.3,
});
// Connect the oscillator to the VCA and to the output
osc.connect(vca).connect(audioContext.destination);
// Start the envelope (attack phase)
vca.gate.setValueAtTime(1, audioContext.currentTime);
// Release it half a second later
vca.gate.setValueAtTime(0, audioContext.currentTime + 0.5);
```

## Parameters

Same as [adsr](/docs/modulators/adsr):

- `gate`: Opens the envelope while positive, releases it at 0. Default is 0.
- `attack`: The attack time in seconds. Default is 0.01.
- `decay`: The decay time in seconds. Default is 0.1.
- `sustain`: The sustain level. Default is 0.5.
- `release`: The release time in seconds. Default is 0.3.
- `offset`: The start offset. Default is 0.
- `gain`: The gain. Default is 1. It is the maximum amplitude after the attack and affects the sustain level. For example, a gain of 100 and sustain of 0.5 will make the sustain level to be 50.

`gate` is read once per render block, so setting it to 1 and back to 0 in the
same tick leaves nothing for the worklet to see. Schedule the edges, as above.

<Callout title="Offset is silence" type="warn">
  The ADSR will output `offset` value when the gate is closed. If you want to
  silence the output, set the `offset` to 0.
</Callout>
